# Kublink - URL Shortener

A highly scalable cloud native URL Shortener written in Go deployed on K8s. 
This is a deliberately designed simple playground the platform and the value is the 
components around it Observability, GitOps, Security and Incident response practise 
and simulation.

The Reason for this project is: 
I feel this project has very clearly well defined scope and can be done on my own 
within a reasonable amount of time. And also make this platform not only a toy project
but maybe this even be a battle tested platform that can run real production workloads.

## Tech Stack:

- Go
- Docker
- Kubernetes
- OpenTelemetry
- Prometheus
- Grafana
